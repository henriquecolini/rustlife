## Ground rules (learned the hard way)
- Content: `--game-dir "/mnt/jupiter/Games/SteamLibrary/steamapps/common/Half-Life 2 Deathmatch"` (not auto-discovered). Inspect files with `target/release/rustlife-inspect --game-dir ... ls|cat|extract|sequences`.
- Particle systems live in `particles/*.pcf` (binary DMX) in the mounted game; materials in `materials/particle/**`, `materials/effects/**`, `materials/sprites/**`.
- Client effects the game draws in code (not PCF) are registered by name with `DECLARE_CLIENT_EFFECT` (strings like `AR2Impact`, `MuzzleFlash_*`); find the registration (xref the name string), take the callback address from the `lea rdx` before it, and read its constants. Sizes of legacy particles (`SimpleParticle`) and `FX_AddQuad` quads are half-sizes; a PCF card's `radius` is a half-size too, a PCF trail's is its full width.
- Reading the game's code: Ghidra/REA times out on `hl2mp/bin/linux64/{server,client}.so` (stripped, 18 MB). What worked: `objdump -d --no-show-raw-insn -M intel X.so > X.asm`, then find a string's address with `strings -t x`, grep `# <addr> ` in the asm for its users, and walk vtables via RTTI (typeinfo name -> typeinfo -> `R_X86_64_RELATIVE` relocs from `readelf -rW` -> vtable slots). ConVar defaults: pairs of `lea rdx,[default]` / `lea rsi,[name]` before `call` in static initialisers. Scripts were scratch files; rewrite them (small Python) if needed. Every ConVar default of a library (name -> default string) falls out of that `lea rdx` / `lea rsi` pair in one pass: that is how `mp_falldamage`, `hl2_normspeed`, `sv_optimizedmovement`, `hud_fastswitch`, `viewmodel_fov` and the rest were read; a ConVar's users are the `[rip+X]` loads of its object address plus 0x38 (the pointer to its parent), then `[rax+0x54]` for the float value.
- GROUND TRUTH: HL2DM itself is installed and can be driven: `steam -applaunch 320 -windowed -noborder -w 1920 -h 1080 -console -novid +map dm_lockdown +sv_cheats 1`; type console commands through a virtual keyboard on /dev/uinput (the console key on a pt-BR layout is the apostrophe key; the first typed line gets a stray `'`), `setpos`/`setang` to a pose, bind a key to `+attack` to fire (mouse clicks do not reach the windowed game), record the window with `ffmpeg -f x11grab -window_id <id>` at 60 fps and compare frames to `rustlife --teleport=X,Y,Z-feet,PITCH,YAW --explode|--pcf NAME|--weapon ID --fire-for S --wait S --screenshot f.png` (`--wait` is jittery to a frame or two). Eye height 64 (feet z = eye z - 64).
- Visual checks of a throw: `--map dm_runoff --weapon manipulator --grab-prop --throw-after 0.8 --throw-pitch 35 --wait=-0.2` (`--throw-pitch` looks up once the prop is held, so it is thrown into the sky; the shot is taken `0.35 + wait` seconds after the throw, so a negative wait catches the effects, which last a tenth of a second).
- Visual checks: `target/release/rustlife --game-dir ... --map dm_lockdown --weapon <id> --teleport=-2843,1928,3,20,84 --fire-for 0.3 --wait 1.0 --screenshot out.png` (build with `cargo build --release -p rustlife`). `--all-weapons` gives everything with infinite ammo.
- Existing client effects are procedural: `crates/rl_client/src/{particles,effects,decals,grenades,laser,zoom}.rs`, config in `data/effects.ron`. Materials: `rl_assets/src/{material,decal,sprite}.rs`, `rl_client/src/world.rs::standard_from`.
- Style: clippy pedantic, docs on public items, tests, data-driven (RON), conventional commits ending with the Co-Authored-By line.

## 1. PCF particle engine (prerequisite for most items below)
1. `source_formats::pcf`: parse DMX binary (versions 1-5, string dictionary, element/attribute types) into particle systems: operators (renderers, initializers, emitters, operators, forces, constraints), children, and their attributes. Test on `particles/*.pcf` from the game (ignored content tests with `RUSTLIFE_TEST_GAME_DIR`).
2. `rl_client::pcf_particles`: a CPU particle runtime for the operators HL2DM's effects actually use (list them by scanning every system named below; implement only those). Renderers: sprite/animated sprite/rope/beam/trail as Bevy billboards or ribbons with the VMT's blend mode (additive, alpha, `$selfillum`). Respect `Exposure`/`Tonemapping::None` look (see world.rs).
3. Spawn by system name from events (explosion, impact, muzzle flash, ...) so `effects.ron` maps names -> events.
